# Bundled webfonts

Self-hosted so the site makes no third-party font request — faster first paint,
no layout shift, and no visitor IP handed to a CDN.

Latin subsets only, taken from the Google Fonts release of each family.
All three are licensed under the SIL Open Font License 1.1, which permits
bundling and redistribution with this site.

| File | Family | Upstream |
| --- | --- | --- |
| `anton-normal-latin.woff2` | Anton | https://fonts.google.com/specimen/Anton |
| `manrope-normal-latin.woff2` | Manrope (variable, 400–800) | https://fonts.google.com/specimen/Manrope |
| `fraunces-normal-latin.woff2` | Fraunces (variable, 400–700) | https://fonts.google.com/specimen/Fraunces |
| `fraunces-italic-latin.woff2` | Fraunces italic (variable, 400–700) | https://fonts.google.com/specimen/Fraunces |
